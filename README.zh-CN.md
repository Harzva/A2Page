# A2Page

A2UI 描述界面；A2Page 给界面一个可保存、可重开、可继续修改的页面身份。首版是一个独立开源库和「会议跟进页」演示，不依赖 Bot Studio 或任何模型供应商。

在 Node.js 24 下执行 `npm ci` 和 `npm run dev`，打开终端给出的地址。点击发送创建请求，再从聊天卡片打开页面。勾选一项、关闭并重开，勾选会重置；选择「Put launch risks first」并发送，同一个页面会新增风险区块并保存为第 2 版。刷新后，原卡片仍打开最新版。

示例请求是脚本驱动的，不使用真实模型或会议资料。页面保存在本浏览器的 IndexedDB 中。当前只有最新版本，不包含公开分享、实时数据和历史回滚。
